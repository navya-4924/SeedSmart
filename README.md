# 🌾 SeedSmart – AI-Powered Farming Assistant

An AI-powered web application that helps smallholder farmers in Kadapa district with crop recommendations, disease detection, and farming advice.

## 🎯 Features

- 🌾 **Crop Recommendation** – Get crop suggestions based on soil conditions
- 🔬 **Disease Detection** – Identify crop diseases from photos
- 💬 **AI Chatbot** – Ask farming questions and get instant answers
- 📱 **WhatsApp Integration** – Access via WhatsApp for easy use
- 🌐 **Telugu Support** – Coming soon
